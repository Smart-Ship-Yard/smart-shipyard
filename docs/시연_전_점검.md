# 시연 전 점검

시연 당일 아침에 이것만 훑으면 되도록 한 장으로 모았다. 각 항목의 자세한
근거는 링크한 문서에 있다.

---

## 1. 미디어 서버 (영상)

```bash
systemctl status mediamtx          # active (running) 이어야 한다
sudo ufw status | grep -E '8554|8889|8189'
```

포트가 **세 개** 다 있어야 한다. 하나가 UDP다.

| 포트 | 방향 | 없으면 |
|---|---|---|
| 8554/tcp | 젯슨 → 서버 | 젯슨이 송출을 못 붙인다 |
| 8889/tcp | 브라우저 → 서버 | 재생 페이지가 안 열린다 |
| **8189/udp** | 브라우저 ↔ 서버 | **페이지는 열리는데 검은 화면** |

> `8189/udp` 를 빠뜨리면 에러 없이 검은 화면만 나온다. 젯슨 송출 문제로
> 착각하기 딱 좋으니 여기부터 본다.

**확인 순서** — 대시보드보다 재생 페이지를 먼저 연다:
`http://192.168.0.5:8889/ugv1` 에서 영상이 나와야 한다. 여기서 안 나오면
프론트 문제가 아니다.

자세히: [`server/streaming/README.md`](../server/streaming/README.md)

## 2. 거리 게이트 — 두 값이 **짝**이다

배에서 멀리 떨어진 오검출을 버리는 값이 양쪽에 하나씩 있다. 지금 **둘 다 1.2 m**.

| 어디 | 값 |
|---|---|
| 젯슨 `change_point.py` 의 `max_dist_from_ship_m` | 1.2 |
| 프론트 `ShipyardTwinDashboard.jsx` 의 `MAX_EVENT_DIST_FROM_SHIP_M` | 1.2 |

> ⚠️ **순찰 반경을 바꾸거나 대상을 배에서 더 멀리 두면 둘 다 올려야 한다.**
> 한쪽만 바꾸면 진짜 이벤트가 조용히 사라진다.
> 프론트는 걸러낼 때 콘솔에 `[이벤트 걸러냄]` 을 남기므로 거기서 확인된다.

젯슨의 `max_depth_m`(2.0)은 **다른 것**이다 — 그건 로봇~대상 거리라 이 문제를
못 잡는다. 헷갈려서 그 값을 만지지 말 것.

## 3. 실행 순서

데이터는 무엇을 먼저 켜든 잃지 않는다(젯슨이 큐와 재통보로 보전한다).
아래는 **관찰 편의** 순서다.

```bash
# ① 백엔드
cd ~/smart-shipyard/backend && venv/bin/uvicorn main:app --host 0.0.0.0 --port 8000

# ② 프론트
cd ~/smart-shipyard/frontend && npm run dev

# ③ 브라우저 localhost:5173  → 상단 배지 "서버 연결됨 / 로봇 끊김" 확인

# ④ 젯슨 (로봇)
```

로봇이 붙으면 재연결 팝업이 뜨고, 확인을 누르면 화면이 새로 불러와진다.

---

## 4. 화면에서 미리 알아둘 것

**위치 표기** — 배 위에서는 좌/우를 말하지 않는다.

| 대상 위치 | 표기 | 예 |
|---|---|---|
| 배 위(갑판) | 구획 + `위` | `S1 위` |
| 배 밖 | 구획 + 좌/우 | `S3 왼편` |
| 배 밖, 앞뒤 넘음 | 구획 + 앞뒤 + 좌/우 | `S1 앞쪽 왼편` |

배 폭이 14cm(반폭 7cm)인데 좌표 오차가 3~5cm 라, 갑판 위 좌/우는 센서
정밀도 안쪽이다. 구획(한 칸 15cm)은 오차보다 3배 커서 믿을 수 있다.
**"S1에 화재"는 믿어도 되고, 갑판 위 좌/우는 애초에 말하지 않는다.**

**서버를 다시 켜면** 그 이전 핑은 화면에서 사라진다(설계된 동작). 다만 로봇이
아직 그 위험을 기억하고 있으면 재연결하면서 다시 알려준다.

## 5. 커밋하면 안 되는 것

- `backend/.env` — 몽고 접속 정보
- `backend/snapshots/*.jpg` — **작업자 얼굴이 찍힐 수 있다**
- 젯슨에서 `git add .` 금지 — `wit_ros2_imu` 서브모듈이 딸려 들어간다

셋 다 `.gitignore` 가 막고 있지만, 사진 쪽은 한 번 올라가면 이력에 남으므로
습관으로도 조심한다.
