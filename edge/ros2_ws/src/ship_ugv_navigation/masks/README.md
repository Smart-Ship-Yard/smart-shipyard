# masks/ — Nav2 KeepoutFilter 마스크

`finalize_map.py` 가 맵마다 자동으로 만든다. **손으로 만들 필요 없다.**

```
keepout_<맵이름>.pgm    검은 사각형 = 로봇이 들어가면 안 되는 영역
keepout_<맵이름>.yaml   해상도·원점 (맵과 반드시 같아야 겹친다)
```

## 무엇에 쓰나

라이다는 지면 약 0.20 m 높이의 **수평면 한 장**만 스캔한다. 그보다 낮은 대상
(모형 배 등)은 맵에도 코스트맵에도 잡히지 않아 **Nav2 가 빈 공간으로 알고
가로질러 간다.** 좌표를 안다고 장애물이 되는 것이 아니다.

KeepoutFilter 는 센서와 무관하게 코스트맵에 영역을 직접 박는다. 스캔
레이트레이싱에 지워지지도 않고, 글로벌·로컬 코스트맵 양쪽에 붙일 수 있다.
(맵 이미지에 칠하는 방식은 `static_layer` 가 있는 글로벌에만 적용되어
컨트롤러 단에서는 여전히 대상을 모른다.)

## 언제 만들어지나

`finalize_map.py` 가 순찰 대상의 위치와 **크기**를 알 수 있을 때만 만든다.

| 크기를 얻는 경로 | 상황 |
|---|---|
| 맵의 포위된 장애물에서 | 대상이 라이다에 잡힐 때 (매핑 중 임시 상자를 놓은 경우 포함) |
| 측량 기록 `size_xy` | 젯슨의 `ship_survey_node` 가 뎁스카메라로 측량한 경우 |
| `--ship-size W H` | 위 둘이 없을 때 손으로 지정 |

셋 다 없으면 마스크를 만들지 않고 그 이유를 출력한다.

## 없으면 어떻게 되나

`navigation.launch.py` 가 필터를 **켜지 않고** 뜬다. 기동 배너에
`keepout : 사용 안 함 — ... 없음` 이라고 찍히므로 로그에서 바로 확인할 수 있다.

필터를 켜 둔 채 마스크 서버가 없으면 `KeepoutFilter` 가
`/costmap_filter_info` 를 기다리다 코스트맵이 활성화되지 못해 **Nav2 가 아예
안 뜬다.** 그래서 기본은 꺼진 상태다.
